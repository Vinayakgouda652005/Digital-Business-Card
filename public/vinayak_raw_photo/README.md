Store Vinayak's raw photographs and cutouts in this folder.

- `vinayak_raw_photo.png`
- `vinayak_raw_photo.jpg`
- `vinayak_raw_photo.jpeg`
- `vinayak_raw_photo.webp`
- `photo.png`
- `photo.jpg`

Public path: `/vinayak_raw_photo/<filename>`
